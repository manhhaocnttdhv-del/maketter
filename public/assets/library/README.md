# Thư viện ảnh Maketter

Thêm ảnh dùng trong website vào thư mục này. Trình chỉnh sửa tự quét các định dạng
PNG, JPG, JPEG, WEBP, GIF, SVG và AVIF trong toàn bộ `public/` và `src/assets/`,
bao gồm thư mục `public/assets/library/` này.

Khi đang chạy môi trường development, thêm, sửa hoặc xóa ảnh sẽ tự tải lại trang.
Khi deploy production, chạy lại `npm run build` để cập nhật thư viện ảnh.
